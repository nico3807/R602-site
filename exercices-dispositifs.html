Dispositifs Interactifs

Créer des expériences interactives créatives et ludiques

Exercice 4 : Particules réactives à la souris

4/6

📋 Contexte

Vous créez une installation interactive : des particules qui réagissent à la position de la souris. Projet purement front-end, canvas HTML5.

⚠️ La piège du prompt trop long

Sur ce type de sujet créatif-technique, il existe un anti-pattern : le prompt trop chargé qui noie l'essentiel. Préférez la concision.

✅ Prompt à utiliser

"[Contexte] Canvas HTML5 avec particules.
[Rôle] Expert Canvas 2D et animations.
[Tâche] Génère 50 particules qui repoussent à l'approche de la souris.
[Format] HTML + CSS + JS commenté.
[Contraintes] Smooth animations, 60fps visé."

🔧 Affinage itératif — exemple

Une fois le premier résultat obtenu, affinez avec des prompts courts qui gardent le contexte : 

"Augmente les particules à 80 et ajoute une légère traînée"
"Rends les particules colorées avec gradient"

🎯 À vous de jouer

  • ✓ Testez le rendu, ajustez la valeur 80 → 120 particules
  • ✓ Défi : Demandez "Ajoute un mode attraction : maintenir clic pour attirer les particules"
  • ✓ Défi+ : Demandez "Comment exporter ce canvas en GIF animé depuis JS ?"

Exercice 5 : Capteurs simulés avec visualisation

5/6

📋 Contexte

Prototype d'interface pour un dispositif physique. En attendant le vrai capteur, des sliders simulent les données. La visualisation se met à jour en temps réel.

✅ Prompt avec rôle fort + données simulées

"[Contexte] Interface de monitoring en temps réel.
[Rôle] UX engineer spécialisé en data visualization.
[Tâche] Crée 3 sliders (température, humidité, pression) 
avec affichage circulaire en direct.
[Format] HTML + CSS + JS, avec SVG ou Canvas.
[Contraintes] Responsive, pas de librairie graphique externe."

🎯 À vous de jouer

  • ✓ Modifiez les plages des capteurs pour coller à un vrai projet
  • ✓ Défi : Ajoutez un 4e capteur : son (0-100 dB) qui fait trembler le cercle
  • ✓ Défi+ : Demandez "Connecte ces sliders à l'API Web Audio pour lire le micro"

Exercice 6 : Jeu de cible avec score

6/6

📋 Contexte

Petite expérience interactive ludique : une cible apparaît à des positions aléatoires, le joueur doit cliquer dessus le plus vite possible. Score et temps moyen affichés.

✅ Prompt avec spécification de comportement

"[Contexte] Mini-jeu interactif de clic rapide.
[Rôle] Game designer front-end.
[Tâche] Crée un jeu : cible circulaire aléatoire, 
clique = +1 score et nouvelle cible.
[Format] HTML + CSS + JS, gamification visuelle.
[Contraintes] Temps moyen, score max, pas de framework."

🎯 À vous de jouer

  • ✓ Testez le jeu et évaluez la difficulté
  • ✓ Défi : Demandez "Ajoute un mode multijoueur local (2 touches clavier différentes)"
  • ✓ Défi+ : Demandez "Enregistre le meilleur score dans le localStorage"

Points-clés pour les dispositifs interactifs

Concision d'abord

Les prompts créatifs ont besoin de clarté, pas de verbosité.

Affinage itératif

Construisez progressivement en utilisant les réponses précédentes.

Tester et itérer

Le rendu visuel révèle rapidement ce qui fonctionne ou non.
