Partie 1 — Installation d'Ollama

Déployer Ollama et télécharger les 3 modèles open-source en local. Suivez les étapes selon votre système d'exploitation.

30 min Terminal requis ~11 Go à télécharger
1.1

Installer Ollama

Rendez-vous sur ollama.com/download et choisissez votre plateforme, ou utilisez la commande correspondante :

Système Commande / Action
🍎 macOS brew install ollama
🐧 Linux curl -fsSL https://ollama.com/install.sh | sh
🪟 Windows Télécharger et exécuter OllamaSetup.exe depuis ollama.com/download
1.2

Démarrer le serveur Ollama

Ollama s'exécute en arrière-plan et expose une API REST sur le port 11434. Vérifiez qu'il est actif : 

# Sur macOS / Linux - démarrage manuel si nécessaire
ollama serve

# Vérification dans un autre terminal
curl http://localhost:11434
# Réponse attendue : Ollama is running
✅ Résultat attendu
La commande curl renvoie : "Ollama is running" — le serveur est prêt à recevoir des requêtes.
💡 Windows : Ollama démarre automatiquement après installation. Cherchez l'icône dans la barre système (🦙). Sur macOS, il démarre aussi automatiquement au login si vous utilisez l'application native.
1.3

Télécharger les 3 modèles

Chaque modèle est téléchargé une seule fois et mis en cache localement. Comptez 5 à 15 minutes selon votre connexion. Vous pouvez lancer les 3 pulls successivement. 

# Modèle 1 : Mistral 7B - performant, équilibré (~4 Go)
ollama pull mistral:7b

# Modèle 2 : Qwen3.1 7B - multilingue, structuré (~5 Go)
ollama pull qwen3:latest

# Modèle 3 : Llama 3.2 3B - léger, rapide (~2 Go)
ollama pull llama3.2:latest

🇫🇷 Mistral 7B

~4 Go — Rapide, excellent en code et raisonnement, très bon instruction-following.

🌍 Qwen3 7B

~5 Go — Multilingue FR/EN, très bon en texte structuré et analyse.

⚡ Llama 3.2 3B

~2 Go — Léger, rapide, idéal pour les machines moins puissantes.

1.4

Premier test rapide en CLI

Pendant que les autres modèles se téléchargent, testez le premier disponible directement dans le terminal : 

# Lancer une session interactive avec Mistral
ollama run mistral
>>> Explique-moi ce qu'est un LLM en 3 lignes.

# Tester Qwen2.5 (multilingue)
ollama run qwen2.5
>>> Quel est ton point fort par rapport aux autres modèles ?

# Tester Llama3.2 (léger)
ollama run llama3.2
>>> Donne-moi une définition simple du machine learning.

# Quitter la session interactive
/bye
📝 Observation à noter
Notez les différences de vitesse et de style de réponse entre les 3 modèles. Ces premières impressions seront à comparer en Partie 5.
1.5

Vérifier les modèles installés

# Lister tous les modèles disponibles localement
ollama list

# Détail d'un modèle (taille, paramètres, famille)
ollama show mistral

La commande ollama list doit afficher les 3 modèles avec leur taille et la date de leur téléchargement. Si un modèle manque, relancez le ollama pull correspondant.

Checklist de validation

Ollama est prêt !
