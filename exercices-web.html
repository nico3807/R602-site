Exercices Web : HTML, CSS, JavaScript

Exercice 1 : Carte avec effet au survol

1/3

📋 Contexte

Vous intégrez une page de présentation d'équipe pour un portfolio MMI. Vous avez besoin d'une carte avec effet au survol.

📝 Étape 1 — Testez le mauvais prompt

Dans VSCode, ouvrez le Copilot Chat et tapez exactement ce prompt, puis observez le résultat : 

"Fais une carte"

✅ Étape 2 — Testez le bon prompt

"[Contexte] Je crée une page d'équipe pour un portfolio MMI.
[Rôle] Tu es un développeur front-end senior.
[Tâche] Génère une carte HTML/CSS avec effet au survol.
[Format] Code HTML + CSS, commenté, dans un seul bloc.
[Contraintes] Sans JavaScript, sans framework, CSS Grid ou Flexbox."

🎯 À vous de jouer

  • ✓ Intégrez la carte dans un fichier index.html
  • ✓ Modifiez le prompt pour obtenir une variante avec thème sombre
  • ✓ Ajoutez une contrainte : "sans JavaScript"
  • ✓ Placer le CSS dans un fichier css séparé

Exercice 2 : Menu responsive hamburger

2/3

📋 Contexte

Vous développez un mini-site MMI. Il faut un nav qui se transforme en menu hamburger sur mobile.

✅ Prompt complet à utiliser

"[Contexte] Je crée un mini-site portfolio MMI.
[Rôle] Tu es un développeur web mobile-first.
[Tâche] Génère une navigation responsive avec menu hamburger.
[Format] HTML + CSS + JavaScript commenté.
[Contraintes] Hamburger apparaît seulement sous 768px, 
animation fluide, pas de framework."

🎯 À vous de jouer

  • ✓ Testez le menu sur mobile (DevTools → mode responsive)
  • ✓ Ajoutez un sous-menu dropdown pour 'Projets' en modifiant le prompt
  • ✓ Demandez à Copilot : "Ajoute l'indicateur de page active avec JavaScript"

Exercice 3 : Formulaire avec validation

3/3

📋 Contexte

Page de contact pour un portfolio. Validation côté client en JavaScript, avant tout envoi.

🔄 Prompts progressifs — technique de l'entonnoir

Au lieu d'un seul gros prompt, utilisez 3 prompts séquentiels. Chaque réponse sert de contexte au suivant.

Prompt 1 : Structure

"Génère le formulaire HTML : nom, email, message"

Prompt 2 : Styling

"Style ce formulaire : moderne, bouton coloré, 
responsive, mobile-first"

Prompt 3 : Validation

"Ajoute la validation JavaScript : 
- email valide (regex)
- nom minimum 3 caractères
- message minimum 10 caractères
- affiche les erreurs en rouge"

🎯 À vous de jouer

  • ✓ Testez la validation avec des valeurs incorrectes
  • ✓ Défi : Demandez "Ajoute un champ de téléphone optionnel avec validation format français"
  • ✓ Défi+ : Demandez "Comment rendrais-tu ce formulaire accessible à un lecteur d'écran ?"
