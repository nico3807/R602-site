La méthode CRTFC en 5 étapes

Pour rédiger un prompt efficace, appliquez la méthode CRTFC. C'est un cadre simple mais puissant pour structurer vos demandes à l'IA.

Lettre Signifie Ce que vous écrivez concrètement
C Contexte "Je développe un site vitrine HTML/CSS/JS vanilla..."
R Rôle "Tu es un développeur front-end expert..."
T Tâche "Génère / Explique / Corrige..."
F Format "Réponds avec du code JS commenté"
C Contraintes "Sans librairie externe / ES6 / Accessible WCAG AA"

Exemple d'application de CRTFC

❌ Avant (prompt vague)

"Fais un formulaire de contact"

Résultat : Code générique, sans contexte de votre projet, possiblement mal structuré ou non accessible.

✅ Après (prompt CRTFC)

"[Contexte] Je développe un site vitrine HTML/CSS/JS vanilla, page contact.html.

[Rôle] Tu es un développeur front-end expert en accessibilité.

[Tâche] Génère un formulaire de contact complet.

[Format] Réponds uniquement avec le code HTML et le CSS associé, commenté.

[Contraintes] Pas de framework, validation HTML5 native, 
labels explicites pour l'accessibilité."
Résultat : Code directement utilisable, adapté à votre contexte et conforme aux standards.
