Partie 2 — Configuration de Continue dans VS Code

Continue est une extension VS Code open-source qui ajoute un assistant IA directement dans votre éditeur. Elle se connecte à Ollama comme backend local.

25 min VS Code requis Ollama doit être actif
2.1

Installer l'extension Continue

Ouvrez VS Code et accédez au panneau des extensions :

1

Ouvrir le panneau Extensions

Ctrl+Shift+X (Windows/Linux) ou Cmd+Shift+X (macOS)

2

Rechercher "Continue"

Tapez Continue dans la barre de recherche.

3

Installer l'extension officielle

Installez "Continue — open-source AI code agent" (éditeur : continue.dev).

4

Recharger VS Code

Attendez que l'installation se termine, puis rechargez VS Code si demandé.

💡 Identification de l'extension
Vérifiez bien que l'éditeur est continue.dev et que le logo est le C orange. C'est l'extension officielle avec plus de 150 000 installations.
2.2

Connecter Continue à Ollama

Une fois installée, Continue doit être configuré pour utiliser Ollama comme fournisseur de modèles :

5

Ouvrir le panneau Continue

Cliquer sur l'icône Continue dans la barre latérale gauche de VS Code (logo C orange).

6

Ajouter un modèle

Dans le panneau Continue qui s'ouvre, cliquer sur le bouton "+ Add a model".

7

Sélectionner Ollama

Choisir le fournisseur : Ollama.

8

Autodetect

Cliquer sur "Autodetect" — Continue détecte automatiquement les modèles installés localement.

9

Sélectionner Mistral

Les 3 modèles (mistral, qwen2.5, llama3.2) apparaissent dans la liste : sélectionner mistral pour commencer.

⚠️ Ollama doit être actif
Si Continue n'autodetecte aucun modèle, vérifiez qu'Ollama est bien démarré (ollama serve dans un terminal). Le serveur doit répondre sur localhost:11434.
2.3

Fichier de configuration config.json

Continue stocke sa configuration dans un fichier JSON. Vous pouvez l'éditer directement via le lien "Open config.json" en bas du panneau Continue. Voici à quoi il ressemble après configuration : 

name: Local Config
version: 1.0.0
schema: v1
models:
  - name: Mistral
    provider: ollama
    model: mistral
    roles:
      - chat
      - apply
  - name: Qwen2.5 7B
    provider: ollama
    model: qwen2.5
    roles:
      - chat
      - autocomplete
  - name: Llama 3.2
    provider: ollama
    model: llama3.2
    roles:
      - chat
      - autocomplete
💡 Les rôles disponibles
chat : utilisé dans le panneau de conversation.
autocomplete : complétion de code inline.
apply : modification directe d'un bloc de code sélectionné.
embed : pour les modèles d'embedding (recherche sémantique).
2.4

Fonctionnalités de Continue à tester

Avant de coder, explorez les 3 usages principaux de Continue :

Fonctionnalité Raccourci Usage
Chat IA Ctrl+L / Cmd+L Poser une question au modèle, obtenir une explication ou du code
Autocomplétion Tab (inline) Suggestions de complétion de code en cours de frappe
Édition rapide Ctrl+I / Cmd+I Sélectionner du code → demander une modification directe
Explication Clic droit → Ask Continue Sélectionner du code → demander une explication
2.5

Exercice de prise en main Continue

🎯 Exercice — Premier contact avec Continue

Créez un fichier test.html dans VS Code et effectuez les actions suivantes :

10

Tester l'autocomplétion

Tapez <!DOCTYPE html> et observez l'autocomplétion de Llama3.2 (appuyez sur Tab pour accepter).

11

Utiliser le chat

Ouvrez le chat Continue (Cmd+L) et demandez : "Génère une page HTML avec un formulaire de contact simple".

12

Édition rapide

Sélectionnez le code généré, faites Cmd+I et demandez : "Ajoute une validation JavaScript sur le champ email".

13

Comparer les modèles

Comparez la qualité des réponses en changeant de modèle via le sélecteur en haut du panneau Continue.

📝 Question de réflexion
Quel modèle produit les suggestions d'autocomplétion les plus pertinentes ? Lequel génère le code le plus lisible depuis le chat ? Notez vos observations.

Continue est configuré !
