Partie 2 : Créer son premier Skill/Gem

Créez un outil de génération de fiches SAÉ - d'abord comme skill Claude, puis comme Gem Gemini

Un projet concret Deux implémentations Travail en binôme

Les 4 questions préalables

Répondez à ces questions en binôme avant de coder. Elles s'appliquent aux deux plateformes.

1. Quel est le déclencheur principal ?

Claude (skill)

« Crée une fiche SAÉ MMI »
« Génère un document de présentation SAÉ »
Identifiez 5 formulations

Gemini (Gem)

Nom du Gem : « Générateur de Fiches SAÉ »
Décrivez quand on l'utilise

2. Quelle est la structure cible ?

Fiche SAÉ MMI minimale :
  • Titre du projet
  • Équipe (4 personnes)
  • Problématique / contexte
  • Compétences mobilisées (codes AC)
  • Stack technique
  • Calendrier / livrables
  • Réflexion personnelle

3. Quelles sont les règles critiques ?

Identifiez les contraintes absolues (ex: codes AC doivent être réels, min 4 compétences, etc.)

4. Quel est le format de sortie ?

Claude : Fichier .docx avec mise en forme
Gemini : Markdown structuré → copier dans Google Docs

Créer votre SKILL.md (Claude)

Ouvrez VSCode et créez le fichier tp-skills/sae-mmi/SKILL.md :

Structure YAML (frontmatter)

---
name: Générateur de Fiches SAÉ
description: "Crée une fiche SAÉ structurée au format Word"
version: 1.0
author: votreNom
---

Instructions

Écrivez :

  • Le workflow (étapes numérotées)
  • La structure de sortie (.docx)
  • Les règles critiques en majuscules

Checklist SKILL.md

  • ☑ Description avec ≥ 5 mots-clés déclencheurs
  • ☑ Workflow numéroté et impératif
  • ☑ Structure de sortie explicite
  • ☑ Règles critiques en majuscules
  • ☑ Testé avec 3 prompts différents
  • ☑ Fichier < 500 lignes (sinon : fichiers references/)

Créer votre Gem (Gemini)

Allez sur gemini.google.com, créez un nouveau Gem et collez ces instructions dans le champ système :

Instructions système recommandées :
Tu es un expert en création de fiches de projet SAÉ pour le BUT MMI. Tu génères des fiches structurées, professionnelles et exploitables. Quand on te demande une fiche SAÉ, tu :
  1. Demandes les informations manquantes (équipe, technologies)
  2. Génères un contenu structuré avec codes AC valides si possible
  3. Proposes une mise en forme Markdown pour Google Docs
  4. Includes une réflexion personnelle pour chaque compétence

Checklist Gem Gemini

  • ☑ Nom clair et mémorisable
  • ☑ Instructions structurées (numérotées ou tirets)
  • ☑ Format de sortie explicitement décrit
  • ☑ RÈGLES ABSOLUES en majuscules pour les contraintes
  • ☑ Testé avec 3 prompts différents
  • ☑ Instructions < 2000 mots (au-delà : fichier joint)

À vous de jouer

1. Préparation (15 min)

  • Répondez aux 4 questions en binôme
  • Listez 5 formulations déclencheuses
  • Identifiez 3-5 règles critiques

2. Implémentation (30 min)

  • Créez votre SKILL.md dans VSCode
  • Configurez votre Gem dans Gemini
  • Ajoutez une section « Exemple » avec une fiche minimale

3. Test & Itération (20 min)

  • Testez 3 fois avec des SAÉ différentes sur les deux
  • Identifiez le problème le plus récurrent
  • Corrigez-le dans votre SKILL.md ou instructions Gem

4. Pair Review

Échangez votre SKILL.md avec un camarade : Sa description est-elle claire ? Peut-il utiliser votre skill sans questions ?

🎯 Défi optionnel

Ajoutez une règle qui empêche la génération d'une fiche avec moins de 4 compétences.
