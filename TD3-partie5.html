Partie 5 — Comparateur de modèles

Envoyer le même prompt aux 3 modèles simultanément via Promise.all() et afficher les réponses côte à côte avec le temps de réponse mesuré.

35 min Promise.all() grille 3 colonnes
5.1

Principe

Ce dernier exercice crée une page qui envoie le même prompt aux 3 modèles simultanément via Promise.all() et affiche les réponses côte à côte avec le temps de réponse mesuré.

🎯 Objectif
comparateur.html : grille 3 colonnes, prompts prédéfinis (liés à vos compétences MMI), mesure du temps, analyse des différences.

L'idée clé derrière Promise.all() :

// Lancer les 3 requêtes en parallèle
const debut = Date.now();
const [rep1, rep2, rep3] = await Promise.all([
  interroger("mistral", prompt),
  interroger("qwen2.5", prompt),
  interroger("llama3.2", prompt)
]);
const duree = Date.now() - debut;
// → durée = temps de la requête la plus lente (toutes en parallèle)

Complétez à l'aide de Continue pour envoyer la requête aux 3 modèles en même temps, attendre les réponses et afficher le temps de réponse de chaque modèle. 

// Structure de base de la fonction de comparaison
async function comparer(prompt) {
  const modeles = ["mistral", "qwen2.5", "llama3.2"];

  const resultats = await Promise.all(modeles.map(async (modele) => {
    const debut = Date.now();
    const res = await fetch("http://localhost:11434/api/generate", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        model: modele,
        prompt: prompt,
        stream: false,
        options: { temperature: 0.7, num_predict: 400 }
      })
    });
    const data = await res.json();
    return {
      modele,
      reponse: data.response,
      duree: Date.now() - debut
    };
  }));

  // Afficher les 3 résultats dans leurs colonnes respectives
  afficherResultats(resultats);
}
