# R602 - Prompter une IA pour coder

## 📋 Description

Site pédagogique complet basé sur le fichier **TD1_prompt_mmi3_dev.docx** pour le TP de prompting en MMI (Béziers).

Ce site enseigne comment **prompter efficacement une IA** (GitHub Copilot, Claude Code, etc.) pour générer du code de qualité production.

## 📁 Structure du projet

```
R602-site/
├── index.html                   # Page d'accueil / Introduction
├── methode.html                 # La méthode CRTFC en 5 étapes
├── exercices-web.html           # Exercices 1-3 : Web (HTML/CSS/JS)
├── exercices-dispositifs.html   # Exercices 4-6 : Dispositifs interactifs
├── copilot-avance.html          # VSCode : Copilot avancé
├── synthese.html                # Synthèse, anti-patterns et templates
├── style.css                    # Feuille de styles responsive
├── script.js                    # JavaScript pour interactions
└── README.md                    # Ce fichier
```

## 🎨 Caractéristiques

✅ **Responsive design** : Fonctionne sur desktop, tablette et mobile  
✅ **Bandeau fixed en haut** : Navigation sticky avec titre du TP  
✅ **Navigation mobile** : Menu hamburger sur petits écrans  
✅ **Design moderne** : Couleurs primaires, shadows, espacements élégants  
✅ **Accessibilité** : Structure sémantique, navigation au clavier  
✅ **Performance** : CSS optimisé, JS léger et efficace  
✅ **Sans dépendances** : HTML/CSS/JS vanilla uniquement

## 📄 Pages

### 1. **Accueil** (`index.html`)

- Présentation générale du TP
- Introduction au problème (l'IA ne lit pas dans vos pensées)
- Les 4 ingrédients d'un bon prompt
- La fenêtre de contexte

### 2. **Méthode CRTFC** (`methode.html`)

- Explication détaillée de la méthode CRTFC
- Tableau de référence (Contexte, Rôle, Tâche, Format, Contraintes)
- Avant/Après : exemple concret
- Quand utiliser GitHub Copilot vs Claude Code

### 3. **Exercices Web** (`exercices-web.html`)

- **Exercice 1** : Carte HTML/CSS avec effet au survol
- **Exercice 2** : Menu responsive hamburger
- **Exercice 3** : Formulaire avec validation JavaScript
- Prompts progressifs et défi+

### 4. **Dispositifs Interactifs** (`exercices-dispositifs.html`)

- **Exercice 4** : Particules réactives à la souris (Canvas)
- **Exercice 5** : Capteurs simulés avec visualisation en temps réel
- **Exercice 6** : Jeu de cible avec score
- Patterns créatifs et affinage itératif

### 5. **Copilot Avancé** (`copilot-avance.html`)

- Commandes slash utiles (/explain, /fix, /tests, /doc)
- Prompts spécifiques pour différents scénarios
- Workflow recommandé dans VSCode
- Pièges courants à éviter

### 6. **Synthèse** (`synthese.html`)

- Anti-patterns à ne plus faire
- 5 principes clés du prompting efficace
- Templates de prompts (composants web, animations, débogage, refactoring)
- Checklist avant chaque prompt
