De la requête vague au résultat professionnel

Apprenez à prompter une IA pour générer du code de qualité production

Durée : 3 heures Niveau : BUT3 MMI IUT Béziers

L'IA ne lit pas dans vos pensées

Les outils comme GitHub Copilot, Claude ou ChatGPT sont capables de générer du code impressionnant… à condition de leur expliquer correctement ce qu'on attend.

  • Une requête floue = code générique, hors contexte, parfois inutilisable
  • Une requête précise = code directement intégrable dans votre projet

Ce TP vous fait alterner entre mauvais prompts et bons prompts sur des projets concrets du parcours MMI, pour que vous voyiez par vous-même la différence de résultat.

Comment l'IA comprend votre prompt

Un LLM fonctionne par prédiction statistique

Il prédit le texte le plus probable en réponse à votre message, basé sur des milliards d'exemples.

Conséquence directe

Plus votre prompt est précis et contextualisé, plus l'IA peut produire un résultat utile.

Les 4 ingrédients d'un bon prompt de code

1

Contexte

"Je développe un site vitrine en HTML/CSS/JS vanilla..."

2

Rôle

"Tu es un développeur front-end expert..."

3

Tâche

"Génère une fonction qui valide un email"

4

Contraintes

"Sans framework, ES6 uniquement, pas de jQuery"

La fenêtre de contexte : sa mémoire limitée

✓ L'IA voit :

  • Le fichier ouvert
  • Vos commentaires
  • L'historique de la conversation

✗ L'IA ne voit pas :

  • Les autres fichiers de votre projet
  • (sauf si vous les mentionnez ou les collez)
💡 Astuce : Décrivez la structure de votre projet en début de conversation.
