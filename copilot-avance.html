VSCode : Copilot Avancé

Maîtriser les modes d'interaction avancés

GitHub Copilot dans VSCode offre plusieurs modes d'interaction. Voici les plus utiles pour le développement web et interactif.

Commandes slash utiles

/explain

Demande à Copilot d'expliquer le code sélectionné

Exemple : Sélectionnez une fonction complexe et tapez /explain pour comprendre son fonctionnement.

/fix

Propose une correction pour le code sélectionné

Exemple : Un bug ? Sélectionnez le code et /fix le corrige directement.

/tests

Génère des tests unitaires pour une fonction

Exemple : Sélectionnez une fonction et /tests crée une suite de tests.

/doc

Génère la documentation d'une fonction

Exemple : Sélectionnez une fonction et /doc produit une documentation JSDoc.

Prompts spécifiques à Copilot dans VSCode

Expliquer du code sélectionné

Sélectionnez une fonction puis demandez :

"Explique cette fonction en détail"
"Pourquoi cette boucle s'arrête-t-elle ?"
"Quel est le rôle de ce callback ?"

Corriger un bug

Identifiez le code problématique et tapez :

"/fix"
"Cette fonction ne retourne pas le bon type"
"Pourquoi ma boucle ne s'exécute pas ?"

Refactorer du code

Sélectionnez et demandez :

"Refactorise cette fonction avec des fonctions fléchées"
"Simplifie ce code avec destructuring"
"Convertis en ES6+"

Générer des données de test

Dans un fichier test, demandez :

"Génère 5 cas de test pour cette fonction"
"Crée des fixtures réalistes"
"Ajoute des edge cases"

Workflow recommandé avec Copilot

1

Écrire le contexte

Commencez par un commentaire CRTFC

2

Autocomplétion

Laissez Copilot compléter votre code

3

Vérifier

Lisez toujours ce qui a été généré

4

Affiner

Utilisez /fix ou des prompts pour améliorer

Pièges courants à éviter

❌ Ne pas lire le code généré

Copilot peut générer du code syntaxiquement correct mais logiquement faux. Relisez toujours.

❌ Accepter les failles de sécurité

L'IA peut générer du code vulnérable (injections SQL, XSS). Validez la sécurité.

❌ Ignorer la performance

Du code fonctionnel ≠ du code rapide. Mesurez les performances.
