Introduction — Le duo Ollama + Continue

Deux outils complémentaires qui transforment votre poste de travail en environnement IA autonome, sans cloud et sans clé API.

15 min 3 modèles open-source 100 % local

Deux outils complémentaires

Ce TD vous fait découvrir deux outils qui, combinés, transforment votre poste de travail en environnement IA autonome : Ollama pour faire tourner les modèles, Continue pour les utiliser directement dans VS Code.

🤖

Ollama

Moteur d'inférence local. Télécharge et exécute des LLM open-source. Expose une API REST sur localhost:11434.

Rôle : le serveur LLM
🧩

Continue

Extension VS Code open-source. Chat IA, autocomplétion, refactoring. Se connecte à Ollama (ou OpenAI, Anthropic…).

Rôle : l'interface développeur

Architecture du TD

👨‍💻 VS Code
Extension Continue
⟷
🌐 Page HTML
fetch() + JSON
⟷
🤖 Ollama
localhost:11434 → LLM GGUF

Ollama agit comme un serveur local : VS Code (via Continue) et vos pages HTML communiquent tous les deux avec lui via des requêtes HTTP standard. Aucune donnée ne quitte votre machine.

Les 3 modèles utilisés

Modèle Taille Éditeur Points forts
mistral:7b 7B (~4 Go) Mistral AI 🇫🇷 Rapide, excellent en code et raisonnement, instruction-following
qwen2.5:7b 7B (~5 Go) Alibaba Multilingue FR/EN, très bon en texte structuré et analyse
llama3.2:latest 3B (~2 Go) Meta Léger, rapide, idéal pour les machines moins puissantes

💡 Pourquoi local ?

🔒 Aucune donnée transmise à un tiers 📡 Fonctionnement hors ligne 💸 Coût zéro à l'usage ⚡ Latence maîtrisée 🏢 Idéal pour des projets professionnels ou sensibles
