Partie 3 — Premier appel API depuis HTML

Consommer directement l'API REST d'Ollama depuis votre propre code JavaScript, sans bibliothèque tierce.

35 min JavaScript + fetch() endpoint /api/generate
3.1

L'API REST d'Ollama

Continue utilise en interne cette même API pour communiquer avec Ollama. Vous allez maintenant la consommer directement depuis votre propre code JavaScript, sans bibliothèque tierce.

Méthode Endpoint Usage
POST /api/generate Génère une réponse à un prompt unique
POST /api/chat Conversation multi-tours avec historique (rôles user/assistant)
GET /api/tags Liste les modèles disponibles localement
GET /api/show Détails techniques d'un modèle (taille, famille, paramètres)
3.2

Structure de la requête JSON

// Corps de la requête POST vers /api/generate
{
  "model": "mistral",
  "prompt": "Explique-moi ce qu'est une API REST.",
  "stream": false,
  "options": {
    "temperature": 0.7,
    "num_predict": 400
  }
}

// Réponse JSON retournée par Ollama
{
  "model": "mistral",
  "response": "Une API REST est...",
  "done": true,
  "total_duration": 2340000000
}

Paramètres expliqués

ParamètreDescription
model Nom du modèle : mistral, qwen2.5 ou llama3.2
prompt Le texte de votre question envoyée au modèle
stream false = attend la réponse complète · true = tokens envoyés un par un (SSE)
temperature Créativité : 0.0 (déterministe) → 1.0 (créatif). Défaut : 0.8
num_predict Nombre maximum de tokens à générer dans la réponse
3.3

Exercice : index.html avec fetch()

🎯 Objectif
Créer une page index.html qui envoie un prompt fixe à Mistral via fetch() et affiche la réponse. Pas d'interface complexe : juste le résultat dans un <div>.

Créez le fichier dans VS Code. Utilisez Continue (Cmd+L) pour vous aider si besoin !

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ollama - Premier test</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 800px;
           margin: 40px auto; padding: 0 20px; background: #f8fafc; }
    #reponse { background: white; border: 1px solid #cbd5e1;
               border-radius: 8px; padding: 20px; margin-top: 20px;
               white-space: pre-wrap; line-height: 1.6; }
    #statut { color: #64748b; font-style: italic; }
  </style>
</head>
<body>
  <h1>Test Ollama</h1>
  <p id="statut">Chargement...</p>
  <div id="reponse">Ma réponse sera ici...</div>

  <script>
    const PROMPT = "Explique le concept de réseau de neurones en 5 phrases.";

    async function interroger() {
      const statut = document.getElementById("statut");
      const reponse = document.getElementById("reponse");
      statut.textContent = "Requête en cours...";

      try {
        const res = await fetch("http://localhost:11434/api/generate", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({
            model: "mistral",
            prompt: PROMPT,
            stream: false,
            options: { temperature: 0.7, num_predict: 400 }
          })
        });
        const data = await res.json();
        // La réponse est dans data.response
        statut.textContent = "Réponse reçue !";
        reponse.textContent = data.response;
      } catch (err) {
        statut.textContent = "Erreur : " + err.message;
      }
    }

    interroger();
  </script>
</body>
</html>
⚠️ Erreur CORS
Si le navigateur bloque la requête, démarrez Ollama avec : OLLAMA_ORIGINS=* ollama serve — ou ouvrez le fichier via Live Server (extension VS Code) plutôt qu'en file://.
