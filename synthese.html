Synthèse — Ce qu'on retient

Anti-patterns à ne plus faire

❌ Le prompt en 5 mots

"Fais un menu"

→ Utilisez toujours au minimum : contexte + objectif + contrainte principale

❌ Le wall of text

Trop de détails simultanés → l'IA perd les priorités

→ Découpez en prompts séquentiels

❌ Copier-coller sans lire

L'IA peut générer du code fonctionnel mais non-sécurisé ou avec des bugs subtils

→ Relisez TOUJOURS le code généré

❌ Tout dans un fichier

"Fais-moi un site complet avec login, dashboard, API…"

→ Une fonctionnalité à la fois

Les 5 principes clés du prompting efficace

1

Soyez précis

Chaque détail compte. "Formulaire de contact" ≠ "Formulaire de contact avec validation email en regex ES6"

2

Donnez du contexte

L'IA a besoin de savoir où votre code s'inscrit. Mentionnez l'architecture générale.

3

Fragmentez

Un gros prompt = une réponse floue. Plusieurs petits prompts = résultats précis.

4

Validez

Testez, relisez, mesurez. Le code généré n'est pas magique, c'est une base.

5

Itérez

Affinez progressivement. Chaque réponse apporte du contexte pour la suivante.

Fiche récap — Templates de prompts MMI

Usage : Remplacez les parties entre [crochets] selon votre projet.

📱 Composant web (HTML/CSS/JS)

"[Contexte] Je développe [type de projet] avec [technos].

[Rôle] Tu es un [spécialité] expert en [domaine].

[Tâche] Génère [fonctionnalité spécifique].

[Format] [HTML/CSS/JS commenté / Code seul / Explique aussi]

[Contraintes] [Sans framework/responsive/accessible/ES6+]"

🎨 Animation / Canvas / Dispositif interactif

"[Contexte] Création d'une [expérience interactive].

[Rôle] Tu es un [créatif technique / developer creative].

[Tâche] Crée [effet visuel / interaction] avec [contraintes tech].

[Format] Code commenté + explique l'approche.

[Contraintes] Performance [60fps/smooth], [pas de dépendances]"

🐛 Débogage

"Voici le code :
[coller le code avec bug]

Le problème : [décrire le symptôme]

Contexte : [où ce code s'exécute]

Aide-moi à trouver la cause et propose une correction."

♻️ Refactoring

"Voici mon code :
[coller le code]

Je veux : [refactoriser / simplifier / améliorer perf]

Critères : [ES6+ / lisibilité / performance]

Propose une meilleure version."

🎓 Conclusion

Prompting n'est pas magique. C'est un craft qui demande de la pratique, de la rigueur et de la réflexion.

La méthode CRTFC n'est pas rigide : adaptez-la à votre contexte. L'important est de donner à l'IA assez d'information pour générer du code utile.

Relisez toujours. L'IA génère une base, pas de la magie. Vous êtes le développeur, elle est votre copilote.
