Développer avec l'IA en local

Installer Ollama et l'extension Continue pour faire tourner un LLM directement sur votre machine, sans cloud.

🦙 Ollama + LLaMA 3 🧩 Extension VS Code 🔒 100 % local

Qu'est-ce qu'Ollama ?

Ollama est un outil facile à utiliser, conçu pour faire fonctionner des modèles de langage de grande taille (LLM) directement et localement sur votre ordinateur. Il est à la fois rapide et léger.

Contrairement à ChatGPT ou Claude, vos données ne quittent jamais votre machine — un avantage majeur pour les projets sensibles ou les environnements sans accès à Internet.

⚡ Rapide et léger

Optimisé CPU/GPU. Utilisable même sans carte graphique dédiée.

🔒 Totalement local

Aucune donnée envoyée sur Internet. Idéal pour les réseaux restreints.

🧩 Intégrable à VS Code

Via l'extension Continue, Ollama s'intègre directement dans votre éditeur.

Ce que vous pouvez faire avec Ollama + Continue

🐛

Bug fix

Détection et correction d'erreurs de syntaxe ou de logique dans votre code.

⚙️

Optimisation

Suggestions pour améliorer les performances ou la lisibilité du code source.

📖

Explication

Demandez à l'IA d'expliquer un bloc de code complexe en langage naturel.

💬

Message de commit

Génération automatique de messages de commit clairs et conventionnels.

Étape 1 — Installer Ollama

1

Télécharger (Windows)

Rendez-vous sur le site officiel et téléchargez le paquet pour votre OS.

🔗 ollama.com/download
2

Installer (macOS)

Si vous avez Homebrew, une seule commande suffit :

brew install ollama
3

Vérifier

Vérifiez que la commande est disponible dans le terminal :

ollama --version
💡 Windows / Linux : Le site d'Ollama propose des installateurs natifs pour toutes les plateformes. Sur Linux, un script curl suffit.

Étape 2 — Télécharger des modèles LLM

Une fois Ollama installé, il faut télécharger des modèles de langage. Nous vous recommandons de télécharger les trois modèles suivants :

Ouvrez votre terminal et tapez successivement ces commandes :

ollama pull mistral:7b
ollama pull Qwen3:8b
ollama pull llama3.2:latest

Une fois téléchargés, testez-en un directement en mode chat :

ollama run llama3.2:latest
📚 Autres modèles : Phi, Gemma… disponibles sur ollama.com/library.

Étape 3 — Installer l'extension Continue dans VS Code

Continue est une extension open-source qui joue le rôle d'un autopilote IA dans VS Code. Elle se connecte à Ollama pour vous permettre de discuter avec le LLM sans quitter votre éditeur.

1

Ouvrir les extensions

Dans VS Code, utilisez le raccourci :

SHIFT + CMD + X  (macOS)
SHIFT + CTRL + X (Windows/Linux)

Ou Préférences → Extensions.

2

Rechercher Continue

Tapez Continue dans la barre de recherche et installez l'extension Continue – Codestral, GPT-4o, and more.

3

Configurer le modèle

Dans le panneau Continue : Add a model → Ollama → Autodetect. Les modèles téléchargés devraient apparaître dans la liste.

💡 Conseil : Continue détecte automatiquement Ollama sur localhost:11434. Pas besoin de clé API.

Cloud vs Local — que choisir ?

✅ Ollama (local)

  • Données confidentielles, aucun envoi réseau
  • Fonctionne hors ligne (réseau IUT restrictif)
  • Gratuit, sans limite de requêtes
  • Contrôle total sur le modèle utilisé

⚠️ Limites d'Ollama

  • Performances inférieures aux modèles cloud
  • Nécessite une machine suffisamment puissante
  • Téléchargement initial du modèle (plusieurs Go)
  • Moins adapté aux tâches très complexes

Vérification de l'installation

Utilisez cette checklist pour vous assurer que tout fonctionne :

✓ Ollama opérationnel

  • ollama --version répond
  • ollama pull llama3.2:latest complété
  • ollama run llama3.2:latest démarre un chat

✓ Continue configuré

  • Extension visible dans VS Code
  • Les modèles listés dans le panel Continue
  • Le chat répond à une question de test
🚀 Test rapide : Ouvrez un fichier JS dans VS Code, sélectionnez un bloc de code et demandez à Continue : "Explique ce que fait cette fonction."
