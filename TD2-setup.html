🔧 Setup - Avant de commencer

Claude.ai

  • Connectez-vous avec votre compte étudiant
  • Créez un dossier tp-skills/ dans VSCode - c'est votre base de travail
  • Créez le fichier tp-skills/mon-skill/SKILL.md
  • Vérifiez l'accès aux compétences (skills) dans Claude.ai sidebar

Gemini Advanced

  • Connectez-vous avec votre compte Google
  • Accédez à gemini.google.com
  • Alternative : Google AI Studio (aistudio.google.com) pour plus de flexibilité
  • Repérez la section « Gems » pour créer vos configurations

Sans configuration vs Avec configuration

❌ Sans configuration

L'IA improvise à chaque session. Même question = réponses différentes. Vous répétez les mêmes instructions.

✅ Avec skill/gem

Vous définissez une fois le mode opératoire. L'IA le respecte à chaque fois. Gain de temps énorme sur la semestre.

Claude vs Gemini - Aperçu

1

Déclenchement

Claude : Automatique (description SKILL.md)
Gemini : Manuel (sélection du Gem)

2

Format

Claude : Fichier Markdown+YAML
Gemini : Champ texte + fichiers

3

Exécution

Claude : Exécute Python/Node.js
Gemini : Optionnel (code execution)

4

Persistance

Claude : Par session
Gemini : Sauvegardé en cloud
