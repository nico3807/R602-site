Partie 1 : Découverte des Skills & Gems

Testez les mêmes demandes sur Claude et Gemini avec et sans configuration

4 exercices Comparaison directe Observation guidée

EX. 1 - Génération de documents Word

Contexte

Vous avez besoin d'un compte-rendu de réunion de projet SAÉ au format Word.

🔵 Avec Claude + Skill DOCX

  • Claude lit son SKILL.md et utilise la librairie Python
  • Génère un vrai fichier .docx structuré
  • Le fichier est livré via un bouton de téléchargement
  • Directement ouvrable dans Word ou LibreOffice

🟢 Avec Gemini + Gem Document

  • Créez un Gem dédié à la génération de documents
  • Gemini génère du contenu structuré en Markdown
  • Vous copiez le résultat dans Google Docs
  • Alternative : exportez depuis Google Docs en .docx

À vous de jouer

Demande standard :
« Génère un compte-rendu de réunion de projet MMI en Word. Titre, date, participants (4 personnes), points clés, décisions, prochaine réunion. »

Testez d'abord sans skill ni Gem, puis avec la configuration. Comparez les résultats.

EX. 2 - Création de présentations PowerPoint

Contexte

Vous préparez une soutenance SAÉ avec 5 slides : titre + équipe, problématique, architecture, démo, bilan.

Prompt de test

« Crée une présentation PowerPoint de soutenance pour mon SAÉ6 »
Projet : application web de gestion de portfolio MMI
Stack : React, TypeScript, Express, PostgreSQL
5 slides avec structure, design sobre, couleurs MMI (bleu/blanc).

🔵 Claude + Skill PPTX

  • Claude exécute Python + python-pptx
  • Génère un fichier .pptx directement téléchargeable
  • Mise en forme cohérente et professionnelle
  • Ouvrable dans PowerPoint sans conversion

🟢 Gemini + Gem Présentation

  • Configurez un Gem avec instructions spécifiques pour les présentations
  • Gemini génère du contenu structuré en Markdown
  • Intégration native : utilisez le bouton IA dans Google Slides
  • Ou copiez le Markdown dans Google Slides manuellement

À vous de jouer

Générez la présentation sur les deux plateformes. Téléchargez le .pptx Claude, importez le Gem Gemini dans Google Slides. Comparez le rendu.

Défi : Demandez d'ajouter une slide de remerciements avec logos sur les deux plateformes.

EX. 3 - Analyse de documents PDF

Contexte

Vous avez le sujet de votre SAÉ en PDF. Les deux plateformes peuvent l'analyser et générer des livrables structurés.

Chaîne Claude

  • Uploadez le PDF dans Claude
  • Le skill file-reading l'analyse
  • Générez un document Word (.docx) avec un planning structuré

Chaîne Gemini

  • Uploadez le PDF directement dans Gemini
  • Gemini lit nativement (contexte jusqu'à 2M tokens)
  • Utilisez votre Gem Document pour exporter en Google Docs
  • Avantage : analyse de longs documents

À vous de jouer

Testez avec votre sujet SAÉ actuelle :

  • Claude : PDF → analyse → Word structuré avec planning
  • Gemini : PDF → analyse → export Google Docs formaté

Question : Dans quel cas utiliseriez-vous chaque outil ?

EX. 4 - Déclenchement automatique vs manuel

Le concept clé

Claude : Les skills se déclenchent automatiquement quand votre prompt contient certains mots-clés de la description.

Gemini : Vous sélectionnez manuellement le Gem avant de formuler votre demande.

Testez ces prompts sur Claude

Trouvez 3 formulations qui DÉCLENCHENT le skill DOCX :

  • « Génère un compte-rendu en Word »
  • « Crée un document .docx avec... »
  • Trouvez la 3ème !

Trouvez 3 formulations qui NE le déclenchent PAS :

  • « Rédige un résumé de réunion en texte brut »
  • « Écris une liste de points clés »
  • Trouvez la 3ème !

Testez sur Gemini

  • Créez 2 Gems différents (ex: Rédacteur Word, Analyste PDF)
  • Testez la sélection manuelle : activez un Gem avant votre prompt
  • Observez la différence de comportement

À vous de jouer

Discussion : Quel système préférez-vous pour votre workflow quotidien - déclenchement automatique ou manuel ?
